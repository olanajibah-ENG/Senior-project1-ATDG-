# تقرير الخطوة 6: ربط التحليل الدلالي بالنظام

**التاريخ:** 2026-10-28
**ملف الاختبارات:** [`core_ai/tests/test_code_doc_integration.py`](../test_code_doc_integration.py)
**البيئة:** حاوية `ai_web` (Python 3.10.20)

## الهدف
المحلّل يلي بنيناه بالخطوات 3 لـ 5 كان شغّال لحاله بالاختبارات بس. بهالخطوة **حطيناه جوا النظام**، فصار يشتغل تلقائياً بكل مقارنة بين الكود والتوثيق. وشلنا الأشياء القديمة يلي كانت تطلّع إنذارات كاذبة.

## شو صار بيصير بالمقارنة، خطوة بخطوة
1. **تقسيم التوثيق وربطه بالكود** (الخطوة 3).
2. **تجهيز طلب لكل كلاس** (الخطوة 4). إذا الكود الأصلي محفوظ مع التوثيق (`code_content`)، بتنبعت الأسطر الحقيقية بأرقامها.
3. **الإرسال للموديل والفلترة** (الخطوة 5).
4. **الفحوصات الثابتة للتوثيق المنظّم** (متل "بيرمي خطأ مقابل بيرجّع None"). بتضل، لأنها دقيقة وما بتكلّف شي.
5. **النتيجة:** التناقضات المعروضة بس بقائمة المشاكل، والباقي بالإحصائيات.
