# دليل الوسم — Code vs Doc (التصنيف الرباعي)

**النسخة:** مسودة 0.1 — 2026-10-23
**المرجع:** تصنيف DocPrism (ISSTA 2026)
**ينطبق على:** عينات DocPrism (Python) + العينات الخاصة بمشروعنا (High-Level و Low-Level).
**لا ينطبق على:** بيانات Cascade — بتنستخدم بوسمها الثنائي الأصلي بدون إعادة وسم.

---

## 1. وحدة الوسم

كل سطر بالوسم = **دالة واحدة + مقطع التوثيق تبعها بس**.

بتشوف:
- كود الدالة كامل (توقيع + جسم)، وتوقيع الكلاس اللي هي فيه إذا لزم.
- مقطع التوثيق اللي بيخص هالدالة (docstring، أو القسم تبعها بالتوثيق المولَّد).

ما بتشوف: مخرجات نظامنا، ولا وسم الشخص التاني. **الوسم مستقل بالكامل** — ممنوع النقاش لحتى يخلص التنين.

## 2. التصنيفات الأربعة

| التصنيف | السؤال اللي بيحسمه |
|---|---|
| `Consistent` | كل ادعاء بالتوثيق صحيح عن الكود، وما في سلوك مهم بالكود ناقص من التوثيق |
| `Direct_Mismatch` | التوثيق بيدّعي شي محدد، والكود بيعمل **شي تاني** بنفس النقطة |
| `Over_Promise` | التوثيق بيدّعي سلوك أو ضمان، والكود **ما بيعمله أصلاً** |
| `Under_Promise` | الكود بيعمل سلوك مهم للمستدعي، والتوثيق **ما بيذكره** |

### 2.1 `Direct_Mismatch` — تناقض مباشر
التوثيق والكود بيحكوا عن نفس الشي وبيختلفوا عليه. أمثلة:
- نوع الإرجاع: التوثيق `Returns int`، الكود بيرجّع `str` أو `Optional[int]`.
- الـ parameters: اسم أو عدد أو ترتيب أو قيمة افتراضية مختلفة.
- الاستثناء: التوثيق `Raises KeyError`، الكود بيرجّع `None` بهالحالة (أو بيرمي `ValueError`).
- الوحدات أو المعنى: التوثيق "timeout بالثواني"، الكود بيتعامل معه بالميلي ثانية.
- مثال بالتوثيق ما بيشتغل على الكود الحالي.

### 2.2 `Over_Promise` — وعد زايد
التوثيق بيضمن شي، وما في بالكود أي منطق بيحققه (مش منطق مختلف — **ما في منطق**). أمثلة:
- "Validates the email format" والكود ما بيفحص شي.
- "Thread-safe" وما في أي lock.
- "Results are cached" وما في cache.
- "Retries 3 times on failure" وما في retry.

### 2.3 `Under_Promise` — وعد ناقص
الكود بيعمل شي **بيحتاج المستدعي يعرفه**، والتوثيق ساكت عنه. "مهم" يعني واحد من هدول بس:
- بيرمي استثناء ما انذكر.
- بيرجّع `None` أو قيمة خاصة بحالات ما انذكرت.
- بيعدّل على المدخلات أو على حالة خارجية (ملف، DB، شبكة، متغير global، state الكلاس) بدون ما ينذكر.
- parameter بيغيّر السلوك بشكل جوهري وما انذكر.

**مش** `Under_Promise`: تفاصيل تنفيذ داخلية، logging، أسماء متغيرات محلية، أو إنو التوثيق مختصر بشكل عام.

### 2.4 `Consistent`
- كل ادعاء محدد بالتوثيق صحيح.
- الكلام العام والغامض ("Handles user operations") ما بيتحاكم — بيعتبر صحيح إلا إذا الكود بيناقضه بوضوح.
- الدالة اللي ما إلها توثيق أبداً **ما بتنوسم** — بتنحط `skip` بعمود الملاحظات (هي مسألة تغطية مش تناقض).

## 3. قواعد الحسم

1. **Direct ولا Over؟** إذا الكود بيعمل بديل للمدّعى → `Direct_Mismatch`. إذا ما بيعمل شي بخصوصه → `Over_Promise`.
2. **أكتر من مشكلة بنفس الدالة:** خود الأعلى أولوية:
   `Direct_Mismatch` > `Over_Promise` > `Under_Promise` > `Consistent`
   واكتب التانية بعمود `secondary_label`.
3. **التوثيق High-Level:** بيتحاكم بس على اللي بيدّعيه. غياب التفاصيل منخفض المستوى (أنواع، parameters) **مش** `Under_Promise` بتوثيق High-Level — إلا إذا كان سلوك من القائمة بـ 2.3.
4. **مش متأكد؟** لا تخمّن. حط أقرب تصنيف وحط `unsure = 1` واكتب السبب. هدول بينحسموا بجلسة التحكيم.
5. **الدليل إلزامي:** لكل تصنيف غير `Consistent`، انسخ العبارة من التوثيق ورقم السطر من الكود بعمود `evidence`.

## 4. أمثلة محلولة

**مثال A — `Direct_Mismatch`**
```python
def get(self, uid: int) -> Optional[dict]:
    """Return the user. Raises KeyError if not found."""
    return self._users.get(uid)
```
التوثيق بيقول بيرمي `KeyError`، الكود بيرجّع `None` بنفس الحالة → بديل للمدّعى.
`evidence: "Raises KeyError if not found" vs L3 .get() returns None`

**مثال B — `Over_Promise`**
```python
def register(self, email: str) -> None:
    """Register a user after validating the email format."""
    self._emails.append(email)
```
ما في أي فحص → وعد بدون تنفيذ.

**مثال C — `Under_Promise`**
```python
def save(self, path: str) -> None:
    """Save the report."""
    if os.path.exists(path):
        os.remove(path)
    ...
```
بيمسح ملف موجود بدون تحذير → أثر جانبي مهم ما انذكر.

**مثال D — `Consistent`**
```python
def area(self) -> float:
    """Compute the area of the rectangle."""
    return self.w * self.h
```

## 5. الإجراء

1. **تجربة أولية (Pilot):** التنين بيوسموا نفس الـ 10 عينات لحالهم، بعدين جلسة نقاش وتعديل الدليل (نسخة 0.2). الـ 10 هدول **ما بينحسبوا** بالـ κ.
2. **الوسم الرئيسي:** كل واحد لحاله على كل العينات (60–90)، بملف `labels_code_vs_doc_<name>.csv`.
3. **قياس الاتفاق:** `python -m evaluation.labeling.kappa <a.csv> <b.csv> --column label`
   - κ على التصنيف الرباعي.
   - κ على الثنائي (`flagged` = غير Consistent) — لأن الـ Flag Rate بيعتمد عليه.
   - **الهدف:** κ ≥ 0.60 (الحد الأدنى المقبول؛ فوق 0.80 ممتاز). إذا أقل: منراجع الخلافات، منعدّل الدليل، ومنعيد الوسم على عينة جديدة.
4. **التحكيم:** الخلافات بتنحسم بنقاش (أو شخص تالت). الوسم النهائي بعمود منفصل، ومنحتفظ بوسم كل شخص الأصلي للتقرير.
5. **بالتقرير:** منذكر κ قبل التحكيم، عدد الخلافات، وأكتر زوج تصنيفات انخلط.

## 6. أعمدة ملف الوسم

| العمود | القيم |
|---|---|
| `sample_id` | من ملف العينة |
| `element` | `Class.method` |
| `label` | `Consistent` / `Direct_Mismatch` / `Over_Promise` / `Under_Promise` / `skip` |
| `secondary_label` | اختياري |
| `unsure` | `0` / `1` |
| `evidence` | العبارة من التوثيق + السطر من الكود |
| `notes` | حر |
